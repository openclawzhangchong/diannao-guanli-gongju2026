## 📦 工具箱概览

本仓库打包了装机人员常用的系统管理工具集合，包含以下模块：

| 模块 | 说明 |
|------|------|
| 🛠️ **WIN装机工具箱.exe** | 主程序，集成常用装机操作 |
| 🧹 **优化清理** | 系统垃圾清理、注册表优化、启动项管理 |
| 📦 **实用工具** | 日常运维常用小工具集合 |
| 🌐 **局域网共享设置** | 快速配置网络共享、打印机共享 |
| ✅ **检测激活** | 系统/Office 激活检测、授权管理 |
| 🔍 **硬件检测工具** | CPU、内存、硬盘、显卡等信息检测 |
| ⚙️ **系统设置** | 系统服务、计划任务、组策略管理 |

## 🚀 快速开始

### 下载

前往 [Releases](https://github.com/openclawzhangchong/diannao-guanli-gongju2026/releases/latest) 页面下载最新版本的压缩包。

### 解压使用

```bash
# 解压压缩包
tar -xf diannao-guanli-gongju2026.tar.gz

# 或直接使用解压工具打开 .tar.gz 文件
# 运行 WIN装机工具箱.exe 即可开始使用
```
